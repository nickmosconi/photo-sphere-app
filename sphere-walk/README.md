# Sphere Walk (branch of Sphere Cam)

The next step after Sphere Cam: walk around a captured place smoothly instead of only turning in one spot.

- Lives in this `sphere-walk/` subfolder of the original Sphere Cam app.
- Reuses Sphere Cam's capture, stitching and viewer code from `../js/` instead of copying it.
- Sphere Cam itself (the pages in the main folder) stays the original app and must keep working.
- Start as a proof of concept, then refine.
- The owner is getting a Mac to build and test a native iOS app; web work stays runnable from the PC.
- The build plan for this branch is in `PLAN.md` in this folder.
